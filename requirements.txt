# Python Dependencies for NiFi IDOL Workarounds
# =============================================
#
# This repository contains NiFi ExecuteScript processors written in Python.
# These processors are executed within NiFi's Python environment.
#
# Core Requirements:
# -----------------
# - Python 3.6+ (typically bundled with NiFi)
# - FFmpeg 4.0+ with libmp3lame (system dependency, not Python package)
#
# Optional Dependencies for Testing/Development:
# ----------------------------------------------
# These are NOT required for NiFi execution, but useful for local development

# For testing the processor logic outside NiFi
# pytest>=7.0.0
# pytest-cov>=4.0.0

# For code quality
# pylint>=2.15.0
# black>=22.0.0

# STT Integration Examples (not required by processor itself):
# sarvam-ai>=1.0.0        # Sarvam AI STT API
# requests>=2.28.0        # For HTTP requests to Sarvam AI API

# Note: The actual processor (mpg_to_mp3_chunks.py) has NO external Python dependencies.
# It uses only Python standard library modules:
# - os
# - subprocess  
# - sys
# - tempfile
